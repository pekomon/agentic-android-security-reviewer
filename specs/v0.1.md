# v0.1 — Android Manifest Security Review


## Goal

Build a focused AI agent that analyzes an Android application's
`AndroidManifest.xml` and produces structured, evidence-based security findings.

The purpose of v0.1 is to establish the basic agent workflow before adding
more advanced capabilities such as orchestration, MCP, sandbox execution,
or multi-provider support.

## Scope

The agent analyzes security-relevant configuration available directly from
`AndroidManifest.xml`.

Initial checks include:

- exported Android components
- application debuggability
- cleartext traffic configuration
- declared and requested permissions
- potentially security-relevant application configuration


## Requirements

### Evidence-based findings

Every security finding must be supported by evidence from the supplied
manifest.

The agent must not invent configuration, components, permissions, or risks
that are not supported by the input.

### Uncertainty

If the manifest alone does not contain enough information to determine
whether something is a vulnerability, the agent must explicitly communicate
the uncertainty instead of presenting the issue as confirmed.

### Structured output

Each finding should contain at least:

- severity
- title
- description
- evidence
- recommendation


### Security reasoning

The agent should distinguish between:

- configuration that is clearly insecure
- configuration that is potentially risky but requires additional context
- normal configuration that should not produce a finding

## Out of scope for v0.1

The following are intentionally excluded:

- application source code analysis
- dependency vulnerability analysis
- APK decompilation
- runtime behavior analysis
- network traffic inspection
- external vulnerability databases
- automatic remediation
- multi-agent orchestration
- MCP integrations


## Success criteria

v0.1 is successful when:

1. A manifest can be provided to the agent for analysis.
2. The agent produces structured security findings.
3. Every reported finding contains evidence traceable to the manifest.
4. The agent avoids findings when evidence is insufficient.
5. The behavior can be exercised using a small set of known test manifests.
