# Agentic Android Security Reviewer

An experimental AI-native security review agent for Android applications.

The goal of this project is to explore production-oriented agentic engineering techniques in a security context, including:

- evidence-based Android security analysis
- tool use
- structured outputs
- behavioral evals
- tracing and failure analysis
- agent orchestration
- model/provider selection

The project starts with a deliberately small scope: analyzing `AndroidManifest.xml` for security-relevant configuration and producing structured findings backed by evidence.

## Status

Early development / learning project.

The implementation will evolve incrementally from a single focused agent toward more advanced agentic workflows.
